# 편집기 개선 개발 계획 (v1.1 ~ v1.3)

작성일: 2026-11-22 / 상태: **승인 대기** (사용자가 "진행해"라고 하기 전까지 시작하지 않음)

## 왜 하는가
v1.0 편집기는 "영상 한 줄을 순서대로 이어 붙이는" 구조라 편집 프로그램의 기본기가 부족하다.
(영상 겹치기, 클립 자유 이동, 소리 분리, 장면 전환, 이미지 등)
CapCut 프로그램 분석(REA)은 하지 않는다. 이용약관 문제가 있고, 필요한 것은 편집기 공통의 기본 동작이라 ffmpeg로 구현 가능하다.
(참고: [결정 기록 001](decisions/001-편집은-ffmpeg-편집목록-방식.md))

## 준비물
**클로드가 직접 하는 것**
- 편집 데이터 구조 개편, 엔진(ffmpeg 필터) 확장, 화면(UI) 구현, 자동 테스트, 브라우저 실제 검증, 문서/커밋
- 소리 파형은 ffmpeg로 만들어서 별도 설치가 필요 없음

**사용자가 하는 것**
- 각 차수 완료 후 직접 써 보고 불편한 점 알려 주기 (몸으로 익히는 방식이라 가장 중요한 역할)
- 2차의 마이크 녹음: 처음 한 번 브라우저/앱의 마이크 허용 누르기
- (선택) 세션을 새로 시작하면 `context7`, `sequential-thinking` MCP가 붙어서 라이브러리 문서 조회와 영향도 분석을 쓸 수 있음. 이번 작업은 구조 개편이라 **세션을 재시작한 뒤 시작하는 것을 권장**

**비용**: 모두 무료 (새 서비스/키 없음). 용량 증가 없음.

## 큰 흐름
| 차수 | 버전 | 주제 |
|---|---|---|
| 1차 | v1.1.0 | 기본기: 구조 개편, 다중 줄, 자유 이동, 소리 분리, 전환 |
| 2차 | v1.2.0 | 소재와 소리: 이미지, 도형, 녹음, 더킹, 평준화, 편의 기능 |
| 3차 | v1.3.0 | 효과와 내보내기: 자동 리프레임, 필터, 키프레임, 일괄 내보내기 |

각 단계가 끝나면 보고하고, 사용자가 "진행해"라고 하면 다음 단계로 간다. (단계마다 커밋 + CHANGELOG)

## 1차 (v1.1.0) 기본기

### 1-1. 데이터 구조 개편 + 엔진
- 모든 클립이 `track`(줄 번호)과 `start`(타임라인 시작 시간)를 가짐. 빈 구간 허용(검은 화면/무음).
- 영상 줄 여러 개: 아래 줄 위에 위쪽 줄이 겹쳐 보임(overlay). 오디오 줄 여러 개.
- 기존 v1.0 프로젝트는 열 때 자동 변환(`version` 필드 도입).
- 엔진: 검은 바탕 캔버스에 클립을 시간 위치에 맞춰 얹는 필터 그래프로 재작성.
- **확인 방법**: 자동 테스트(겹침, 빈 구간, 구 프로젝트 변환) + 내보낸 mp4 프레임 확인.

### 1-2. 타임라인 편의 (UI)
- 클립 자유 드래그 이동(줄 사이 이동 포함), 자석(클립 끝/재생 위치/0초에 붙음)
- 줄별 잠금, 숨기기, 음소거, 줄 추가/삭제
- 여러 개 선택(Shift/Ctrl, 드래그 박스), 일괄 이동/삭제
- 복사/붙여넣기/복제(Ctrl+C/V/D), 삭제 시 뒤를 당기는 옵션(리플)
- **확인 방법**: 브라우저에서 직접 조작 + 사용자 체험.

### 1-3. 소리 분리
- 영상 클립 우클릭 "소리 분리": 오디오 줄에 소리가 생기고 영상은 자동 음소거. 분리된 소리는 원본 클립과 연결(같이 이동).
- **확인 방법**: 분리 후 내보낸 파일의 소리 길이/위치 확인.

### 1-4. 장면 전환
- 붙은 두 영상 클립 사이에 전환(크로스페이드, 디졸브, 슬라이드 등) + 길이 조절. 소리도 함께 부드럽게 이어짐.
- 미리보기에서는 근사치로 표시(최종은 내보낸 파일 기준).
- **확인 방법**: 내보낸 mp4의 전환 구간 프레임 확인.

### 1-5. 레이어 속성 + 파형
- 위쪽 레이어의 위치/크기/투명도(화면 속 화면)
- 오디오 클립에 소리 파형 표시
- 정지 화면(프리즈 프레임), 영상 쪽 페이드
- 자동 저장과 복구(창이 꺼져도 작업 내용 복원)

### 1-6. 점검과 문서
- 전체 재검토, 테스트, ruff/semgrep 0건, 기능설명서/구성도/CHANGELOG 갱신, v1.1.0 커밋

## 2차 (v1.2.0) 소재와 소리
- 이미지 클립(사진 슬라이드쇼, 표시 시간 지정), 단색/배경 클립
- 도형(박스, 원, 화살표), 스티커/로고/GIF 오버레이
- 마이크 녹음(내레이션)
- 오디오 더킹(내레이션 때 배경음악 자동 작게), 음량 평준화
- 구간 반복 재생(In/Out), 마커, 묶기/연결, 속성 복사 붙여넣기, 시간 입력 이동

## 3차 (v1.3.0) 효과와 내보내기
- 자동 리프레임: 9:16로 바꿀 때 화면을 꽉 채우고 위치 조정 (검은 띠 문제 해결)
- 필터/색 보정(밝기, 대비, 채도, 흑백, 블러), 좌우 반전/회전, 역재생
- 키프레임(위치, 크기, 투명도, 볼륨의 시간 변화)
- 내보내기 설정(해상도, 화질, 프레임 수, 오디오만 mp3, GIF), 표지 선택, 프레임 캡처
- 일괄 내보내기(16:9 + 9:16 + 1:1 한 번에)

## 보류 (큰 작업이라 별도 판단)
자동 자막(음성 인식), 무음 구간 자동 컷, 배경/노이즈 제거, 크로마키, 영상 안정화
(모델 설치가 필요해 용량과 속도 부담이 있음)

## 위험과 대응
| 위험 | 대응 |
|---|---|
| 구조 개편으로 기존 프로젝트가 안 열림 | `version` 필드와 자동 변환, 변환 테스트 |
| 겹침/전환에서 ffmpeg 필터 그래프가 복잡해짐 | 엔진을 작은 함수로 나누고 케이스별 자동 테스트 |
| 미리보기와 결과가 다름 | 미리보기는 근사치임을 화면에 표시, 최종은 내보내기 파일로 확인 |
| 긴 영상에서 내보내기 느림 | 진행률 표시 유지, 3차에서 화질/속도 옵션 제공 |
| 라이브러리/ffmpeg 옵션 변경(예: ffmpeg 9) | 기억에 의존하지 않고 실행으로 확인, 가능하면 context7 문서 조회 |

## 자체 검토 메모
- 1차에 사용자 제안 범위(구조, 소리 분리, 전환, 자석, 복사, 다중 선택, 줄 잠금/음소거, 파형, 정지 화면, 자동 저장)를 모두 반영.
- 이전 대화에서 "이번 범위"로 말했던 이미지 클립, 더킹, 평준화, 자동 리프레임, In/Out, 마커, 묶기, 표지/캡처, 해상도 선택은 위험을 줄이기 위해 2~3차로 나눠 배치함.
- 확인 필요: 장면 전환 종류별 ffmpeg 지원 목록(실행으로 확인 예정), 전환과 다중 줄을 같이 쓸 때의 처리 방식.
