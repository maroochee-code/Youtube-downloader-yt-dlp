# 편집 기능 설명서 (기획자용, v1.4)

위쪽 **[편집]** 탭을 누르면 편집 화면이 열립니다. 다운로드 탭 저장 목록의 영상에 마우스를 올리면 나오는 ✂ 버튼으로도 바로 들어올 수 있습니다.

## 화면 구성
| 위치 | 역할 |
|---|---|
| 왼쪽 | 소재: 영상 / 오디오 / 자막 / 글자 탭. 항목을 누르면 타임라인에 들어갑니다 |
| 가운데 | 미리보기. ▶ 또는 Space로 재생 |
| 오른쪽 | 속성. 선택한 항목의 세부 값. 빈 곳을 선택하면 프로젝트 설정(화면 비율) |
| 아래 | 타임라인: 영상 / 오디오 / 자막 / 글자 줄. 빨간 선이 재생 위치 |

## 기본 작업
1. 왼쪽 **영상** 탭에서 영상을 눌러 추가합니다. (여러 개를 넣으면 순서대로 이어 붙습니다)
2. 자르기: 클립 양끝을 끌거나, 빨간 선을 놓고 **나누기(S)** → 필요 없는 조각 선택 후 **삭제(Delete)**. 오른쪽 패널에서 시작/끝 숫자를 직접 입력할 수도 있습니다.
3. 오디오: **오디오** 탭에서 파일을 고르거나 **내 PC에서 불러오기**. 오른쪽에서 볼륨·페이드를 조절합니다. 영상의 원래 소리를 끄려면 클립을 선택하고 "소리 끄기".
4. 자막: **자막** 탭 → "현재 위치에 자막"을 누르고 오른쪽에서 내용과 시간을 입력. SRT 파일 불러오기/내보내기도 가능합니다. 글자 크기·색·위치는 자막 탭 아래쪽 설정.
5. 글자: **글자** 탭 → 제목 같은 글자를 원하는 위치에 얹습니다.
6. 화면 비율: 빈 곳을 눌러 선택을 해제하고 오른쪽에서 선택 (9:16은 쇼츠용).
7. 오른쪽 위 **내보내기**를 누르면 아래 진행 표시줄이 차고, 끝나면 다운로드 폴더에 새 mp4 가 생깁니다. 원본은 그대로입니다.

## 단축키
Space 재생/정지 · S 나누기 · Delete 삭제 · ←/→ 한 프레임(Shift는 1초) · Ctrl+Z 되돌리기 · Ctrl+Y 다시 실행 · Ctrl+S 저장

## 저장
[저장]은 프로그램 폴더의 `projects` 폴더에 편집 목록을 저장합니다. 영상 파일 자체를 복사하지 않으니, 원본을 지우면 열었을 때 "원본 파일을 찾을 수 없습니다"가 나옵니다.

## 알아둘 점
- 미리보기의 페이드·속도는 근사치입니다. 최종 결과는 내보낸 파일로 확인하세요.
- 자막 글꼴은 윈도우 기본 "맑은 고딕"입니다.
- 내보내기는 항상 다시 인코딩합니다(정확하지만 긴 영상은 시간이 걸립니다).

## v1.1 새 기능
- **여러 줄**: 영상 줄(V1, V2…)과 오디오 줄(A1, A2…). 위쪽 영상 줄이 아래쪽 위에 겹쳐 보입니다. 툴바의 ＋영상 줄/＋오디오 줄로 늘립니다.
- **자유 이동**: 클립을 끌어서 원하는 시간과 줄로 옮깁니다. 빈 구간은 검은 화면/무음이 됩니다. 🧲 자석이 켜져 있으면 다른 클립 끝, 재생선, 0초에 딱 붙습니다.
- **라이브러리에서 끌어다 놓기**: 왼쪽 목록의 영상/오디오를 타임라인 줄 위로 끌면 그 위치에 들어갑니다.
- **소리 분리**: 영상 클립 선택 → 🔊 소리 분리. 소리가 오디오 줄로 나오고 영상은 음소거됩니다. 소리는 따로 움직입니다. 같이 움직이게 하려면 🔗 연결, 다시 따로 쓰려면 연결 해제.
- **장면 전환**: 같은 줄에서 클립을 선택하고 오른쪽 "장면 전환"에서 종류와 길이를 고르면 앞 클립과 겹치면서 전환됩니다. (디졸브, 4방향 슬라이드)
- **레이어 속성**: 클립의 위치/크기/투명도로 화면 속 화면(로고, 작은 창)을 만듭니다. 페이드 인/아웃은 영상과 소리에 함께 적용됩니다.
- **정지 화면**: 재생선 위치에서 ❄ 정지 화면 → 그 장면이 2초 멈춥니다(길이는 오른쪽에서 조절).
- **선택/복사**: Shift/Ctrl 클릭 또는 빈 곳을 끌어 상자로 여러 개 선택. Ctrl+C/V/D 로 복사/붙여넣기/복제, Ctrl+A 전체 선택.
- **삭제 2종류**: Delete는 빈칸을 남기고, Shift+Delete(⇤ 당겨서 삭제)는 뒤 클립을 앞으로 당깁니다.
- **줄 설정**: 줄 왼쪽의 👁(숨기기), 🔇(소리 끄기), 🔒(잠금: 실수로 건드리지 않게).
- **파형과 자동 저장**: 오디오 클립에 소리 파형이 보입니다. 편집 내용은 자동 저장되어, 앱이 꺼져도 다시 열면 복구할지 물어봅니다.

## 알아둘 점 (v1.1)
- 같은 줄에서 전환 없이 겹치면 뒤 클립이 앞 클립을 덮습니다.
- 파형은 처음 한 번 계산하느라 잠시 걸릴 수 있습니다.

## v1.2 새 기능
- **이미지**: 영상 탭 → 🖼 이미지 불러오기. 3초짜리 정지 화면으로 들어가며 길이는 오른쪽에서 조절합니다. 투명 배경 PNG는 로고/스티커로 쓸 수 있습니다. (움직이는 GIF는 첫 장면만 사용)
- **도형**: 도형 탭 → 사각형, 원, 배경색(전체 화면). 색/크기/위치/투명도를 바꿀 수 있고, 사각형을 얇게 만들면 선이 됩니다.
- **녹음**: 오디오 탭 → 🎙 녹음. 영상이 있으면 같이 재생되며 말하고, 다시 누르면 재생선이 있던 위치부터 오디오로 들어갑니다. (처음에 마이크 허용 필요)
- **더킹**: 배경음악 오디오 클립을 선택하고 "더킹"을 켜면, 영상 소리나 다른 오디오가 나오는 동안 자동으로 작아졌다가 돌아옵니다. 작아질 때의 음량은 오른쪽에서 정합니다.
- **음량 평준화**: 빈 곳을 눌러 프로젝트 설정에서 켜면 내보낼 때 전체 소리 크기가 일정하게 맞춰집니다.
- **반복 구간**: I(시작), O(끝)로 구간을 정하고 L 또는 🔁로 반복 재생. X로 해제.
- **마커**: M으로 재생선 위치에 깃발. 깃발을 누르면 이동, 오른쪽 클릭으로 삭제. 이름은 프로젝트 설정에서 바꿉니다.
- **묶기**: 여러 개 선택 후 Ctrl+G. 하나를 누르면 같이 선택되고 같이 움직입니다. Ctrl+Shift+G로 풉니다.
- **속성 복사**: 클립 선택 → 속성 복사, 다른 클립 선택 → 속성 붙여넣기 (위치/크기/투명도/볼륨/페이드).
- **이동 칸**: 미리보기 아래 칸에 `1:23.5` 처럼 입력하고 Enter. ⛶ 는 전체 화면.

## v1.3 새 기능
- **효과**: 클립을 선택하면 오른쪽에 화면 맞춤, 회전, 좌우/상하 반전, 밝기/대비/채도, 흑백, 흐림이 나옵니다. 역재생은 120초 이하 구간만 가능합니다. (미리보기의 회전·역재생은 근사치)
- **화면 가득 채우기**: 프로젝트 설정(또는 내보내기 창)에서 켜면 9:16 등으로 바꿀 때 검은 띠 없이 영상으로 꽉 채웁니다. 넘치는 부분은 잘리며, 클립의 가로/세로 위치를 바꿔 보이는 부분을 고릅니다. 클립별로는 "화면 맞춤"에서 따로 정할 수 있습니다.
- **키프레임**: 클립 선택 → ◆ 현재 위치에 키프레임. 재생선을 다른 위치로 옮겨 위치/크기/투명도를 바꾸면 자동으로 키프레임이 생기고 사이가 부드럽게 움직입니다. 타임라인의 노란 마름모를 누르면 그 위치로 이동합니다. (투명도 키프레임은 내보내기가 느릴 수 있음)
- **내보내기 창**: 형식(mp4 / GIF / mp3 소리만), 해상도(480p~4K), 화질, 프레임 수를 고릅니다. 체크하면 16:9, 9:16, 1:1을 한꺼번에 만들어 줍니다(차례로 처리).
- **화면 저장**: 📷 화면 저장은 재생선 위치의 화면(자막, 겹침, 효과 포함)을 PNG로 다운로드 폴더에 저장합니다.
- **표지 지정**: 🖼 표지 지정으로 고른 화면이 mp4의 대표 이미지(미리보기 그림)로 들어갑니다.

## v1.4 새 기능
- **미리보기에서 직접 편집**: 미리보기 화면의 클립/도형/이미지/글자를 누르면 파란 테두리가 나옵니다. 안쪽을 끌면 이동(화면 중앙에 붙는 노란 안내선), 모서리를 끌면 크기, 위쪽 동그라미를 끌면 회전(Shift = 15도 단위). 도형은 변(위/아래/좌/우)을 끌면 가로/세로가 따로 바뀝니다. 키프레임이 있는 클립은 끈 결과가 현재 위치의 키프레임으로 저장됩니다. 빈 곳을 누르면 선택이 풀립니다. (자막은 위치가 위/가운데/아래 3가지라 손잡이가 없습니다)
- **슬라이더**: 오른쪽 속성의 숫자 칸 옆에 슬라이더가 있습니다. 끄는 대로 미리보기에 반영되고, 숫자로 정확히 입력할 수도 있습니다.
- **자막/글자 연출**: 자막 탭 아래 "자막 공통 연출"에서 모든 자막의 기본 연출을 정하고, 자막을 선택해 "이 자막만 따로 연출"로 개별 설정합니다. 글자는 선택하면 바로 설정합니다.
  - 등장: 페이드, 타이핑, 팝업, 슬라이드(4방향), 흐림에서 또렷하게, 줌인
  - 퇴장: 페이드
  - 움직임: 흔들림, 둥둥, 흐르는 자막(좌/우, 자막 길이가 길수록 천천히)
  - 노래방 채우기(글자 색이 차례로 채워짐), 배경 박스(색/진하기)
  - 미리보기와 내보낸 결과는 모양이 약간 다를 수 있습니다. 최종은 내보낸 파일 기준.
- **연결/연결 해제**: 영상 클립과 소리를 선택하고 🔗 연결(같은 파일이면 하나만 선택해도 자동). 연결되면 같이 움직이고 지우거나 나눌 때도 같이 처리됩니다.
