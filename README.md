# YT 다운로더

[yt-dlp](https://github.com/yt-dlp/yt-dlp) 기반의 Windows용 영상/음원 다운로더입니다.
크롬처럼 큰 주소창 하나에 주소를 붙여넣고 미리보기 또는 다운로드를 누르면 끝납니다.
별도 설치 없이 폴더째로 실행하는 포터블 방식으로도 배포할 수 있습니다.

## 주요 기능

- **큰 주소창**: 전체 주소가 줄바꿈되어 모두 보입니다. Enter는 미리보기, Ctrl+Enter는 다운로드, 붙여넣기 시 자동 미리보기, Ctrl+L로 주소창 포커스.
- **영상 / 음원 선택**: 해상도(2160p~144p), 컨테이너(mp4/webm/mkv), 음원 형식(mp3 등) 선택.
- **미리보기**: 임베드가 허용된 영상은 플레이어로 재생하고, 불가한 영상은 썸네일과 안내를 보여줍니다. 다운로드는 그대로 가능합니다.
- **고급 옵션**: 자막, 구간 자르기, 썸네일/메타데이터/챕터 삽입, SponsorBlock 구간 제거.
- **재생목록**: 항목을 골라서 받기, 이미 받은 영상 건너뛰기(archive).
- **프리셋**: 기본 / 음악 / 강의 / 최고화질.
- **오른쪽 사이드바**: 저장한 영상을 썸네일 목록으로 보여주고, 클릭하면 재생, 📂로 폴더에서 열기. 다운로드 폴더 변경 버튼.
- **설정(⚙)**: 저장 폴더, 파일명 규칙, 속도 제한, 재시도, 프록시, 쿠키(브라우저), 테마(다크 기본 / 라이트 / 시스템).
- **⋮ 메뉴**: 지원 사이트 목록(1,200개 이상), 폴더 열기, yt-dlp 업데이트 확인, 정보, 종료.
- **yt-dlp 업데이트**: 사이트 정책이 바뀌어 다운로드가 실패하면 프로그램 안에서 최신 yt-dlp로 갱신 후 재시작할 수 있습니다.
- **일반 프로그램처럼 동작**: 창을 열면 내부 서버가 함께 시작되고, 창을 닫으면 모두 종료됩니다.

## 구성

| 구성 요소 | 설명 |
|---|---|
| Python + FastAPI + uvicorn | 로컬 서버 (yt-dlp를 라이브러리로 호출) |
| 바닐라 HTML/JS | `static/index.html` 단일 페이지 UI |
| pywebview (WebView2) | 앱 창. 없으면 Edge `--app` 창으로 대체 |
| PyInstaller | 포터블 폴더(exe) 빌드 |

## 소스에서 실행

Windows, Python 3.10 이상, [ffmpeg](https://ffmpeg.org/)가 필요합니다.

```bash
pip install -r requirements.txt
python app.py
```

`run.bat`을 더블클릭하면 필요한 패키지를 확인한 뒤 콘솔 창 없이 실행합니다.
ffmpeg는 PATH에 있거나, 프로젝트의 `ffmpeg_bin/`(빌드 시 `ffmpeg/`)에 `ffmpeg.exe`, `ffprobe.exe`를 두면 사용합니다.

옵션: `--port 8765`, `--no-window`(창 없이 서버만 실행)

## 포터블 빌드

```bash
pip install pyinstaller
# ffmpeg_bin/ 에 ffmpeg.exe, ffprobe.exe 를 넣은 뒤
build_exe.bat
```

`dist\YT다운로더` 폴더가 만들어집니다. 폴더째로 압축해 전달하면 Python 없이 `YT다운로더.exe`만 실행하면 됩니다.

- 첫 실행 시 Windows SmartScreen 경고가 나오면 "추가 정보 → 실행"을 누르세요.
- 창이 열리지 않으면 Microsoft WebView2 런타임이 필요한 환경일 수 있습니다.
- 빌드된 exe는 설정(`config.json`)과 업데이트된 yt-dlp(`yt_dlp_update/`)를 exe 옆에 저장하므로, 쓰기 가능한 위치에 두세요.
- ffmpeg를 함께 배포하면 해당 빌드의 라이선스(GPL 등)를 따라야 합니다.

## 알려진 사항

- yt-dlp가 JavaScript 런타임이 없다는 경고를 출력할 수 있습니다. 현재는 모든 화질이 정상 조회되지만, 사이트 변경으로 추출이 실패하면 yt-dlp 업데이트를 먼저 시도하세요.
- 다운로드는 파일명 충돌을 막기 위해 한 번에 하나씩 순서대로 처리됩니다.
