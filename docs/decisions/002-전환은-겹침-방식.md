# 결정: 클립 겹침 = 장면 전환, 모든 클립은 (줄, 시작 시간)을 가진다

## 고른 것
- 모든 클립/오디오가 `track`(줄 번호)와 `start`(시작 시간)를 가진다. 빈 구간 허용.
- 같은 줄에서 뒤 클립이 앞 클립과 겹치고 `trans`(전환 종류)가 있으면 겹친 구간이 전환 길이가 된다.
- 내보내기는 검은 바탕 위에 클립을 줄 순서대로 overlay 한다. 디졸브는 알파 페이드, 슬라이드는 overlay 위치 식으로 만든다.

## 이유
- 전환 길이를 따로 저장하지 않아 겹침 길이와 어긋날 일이 없다.
- xfade 필터 없이 overlay 로 통일되어 다중 줄 겹침/투명도/위치와 같은 방식으로 처리된다.
- 미리보기도 같은 규칙(겹침 구간 계산)으로 그릴 수 있다.

## 다른 후보
- 클립 사이에 별도 전환 객체를 두는 방식: 클립을 옮길 때 전환이 어긋나거나 사라지는 문제가 생겨 보류.
- ffmpeg xfade: 한 줄 이어 붙이기엔 쉽지만 다중 줄/위치 변경과 섞기 어려움.

## 한계
- 슬라이드는 "뒤 클립이 밀려 들어오는" 방식뿐이다(앞 클립이 밀려 나가는 push 는 없음).
- 같은 줄에서 전환 없이 겹치면 뒤 클립이 앞 클립을 그냥 덮는다.
