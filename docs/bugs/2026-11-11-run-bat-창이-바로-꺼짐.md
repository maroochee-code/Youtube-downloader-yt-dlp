# run.bat 실행 시 cmd 창만 깜빡이고 종료

- **증상**: run.bat을 실행하면 cmd 창이 잠깐 뜨고 앱 창은 열리지 않음. (포터블 exe는 정상)
- **원인**: 설치된 `fastapi` 0.115.12와 `starlette` 1.10.0의 버전이 맞지 않음.
  `app.py`의 `FastAPI()` 생성 단계에서 `TypeError: Router.__init__() got an unexpected keyword argument 'on_startup'` 발생.
  run.bat은 `pythonw`로 실행하므로 오류 메시지가 화면에 보이지 않고 그냥 꺼진 것처럼 보임.
  (포터블 exe는 빌드 당시 버전이 들어 있어 영향 없음)
- **해결**: `pip install -U fastapi` (0.162.4로 업데이트). `requirements.txt`에 `fastapi>=0.160` 하한 추가.
- **확인**: `app.py --no-window`와 `pythonw app.py` 모두 서버가 정상 응답함.
- **관련 파일**: `requirements.txt`, `run.bat`, `app.py`
- **다음에 같은 증상이 나오면**: 터미널에서 `python app.py`로 직접 실행하면 오류 메시지가 보임.
