# 결정: 영상 편집은 "편집 목록(JSON) + ffmpeg" 방식으로 만든다

## 고른 것
화면에서는 편집 목록(어느 영상의 몇 초~몇 초, 오디오, 자막 등)만 고치고, 내보내기 때 ffmpeg 한 번으로 영상을 만든다.
원본은 건드리지 않고 새 파일로 저장한다.

## 이유
- ffmpeg 이 이미 프로그램에 들어 있어 추가 설치가 없다. (자막 필터 libass 포함 확인)
- 편집 목록은 글이라서 저장/열기/되돌리기가 쉽고, 변환 코드를 자동 테스트하기 쉽다.

## 다른 후보
- **캡컷 프로그램 분석(REA)**: 하지 않음. 캡컷 이용약관이 역분석을 금지하고, ffmpeg 로 충분하다. 화면 구성만 일반적인 편집기 배치를 참고.
- **MoviePy 등 파이썬 편집 라이브러리**: 느리고 포터블 용량이 커짐.
- **브라우저(WebCodecs/ffmpeg.wasm)에서 편집**: 큰 영상에서 느리고 불안정.

## 한계
- 미리보기는 브라우저 플레이어 기반이라 페이드·속도 변경이 근사치다. 최종 결과는 내보낸 파일 기준.
- 9:16 등으로 바꿀 때 원본 비율이 다르면 남는 곳은 검은색(채워서 자르기는 아직 없음).
- 내보내기는 항상 재인코딩(정확하지만 느림). 자르기만 할 때 빠른 복사 모드는 아직 없음.
