# 이미지/도형이 있는 프로젝트에서 정지(pause)와 녹음 저장이 실패

- **증상**: 이미지나 도형 클립이 있을 때 ⏸ 정지를 누르면 "v.el.pause is not a function" 오류가 나고, 녹음을 끝내도 오디오가 추가되지 않음
- **원인**: 미리보기가 모든 클립을 영상(video) 요소로 가정하고 `pause()`를 불렀는데, 이미지는 `<img>`, 도형은 `<div>` 요소라 해당 함수가 없음
- **해결**: 요소 종류(`kind`)를 기억해 두고 영상 요소에만 재생/정지 호출 (`stopAll`, `syncPreview`)
- **함께 고친 것**: 미리보기 스타일이 `video`에만 적용돼 이미지/도형이 안 보이던 CSS 선택자(`#edStage .lyr`)
- **관련 파일**: `static/editor.js`, `static/editor.css`
- **발견 경로**: 브라우저로 직접 조작해 보는 검증에서 발견 (자동 테스트는 서버 쪽만 다룸)
